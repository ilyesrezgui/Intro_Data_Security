# Synthetic Time Series Generation using TimeGAN and Model Inversion

## Project Description
This project focuses on generating synthetic time series data using a TimeGAN-based approach and exploring model inversion techniques to improve the realism of generated data.

The main goals were:
- Build a simple generator using LSTM networks.
- Train on normalized sequential synthetic data.
- Generate synthetic time series sequences that preserve temporal dependencies.
- Investigate model inversion concepts for improving synthetic data fidelity.

## Methods
- Python programming language
- TensorFlow library for deep learning (LSTM)
- Synthetic random dataset created for training
- MinMaxScaler for data normalization
- Visualization with Matplotlib
